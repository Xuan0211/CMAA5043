# Personal Portfolio Website Project

## Project Overview
This is a multi-page personal portfolio website built with semantic HTML5 and CSS3. It includes a homepage with multimedia elements, a project showcase with sub-pages, and a contact form.

## File Structure
- `index.html`: The main homepage of the website.
- `projects.html`: Homepage for the project section, linking to sub-projects.
- `contact.html`: Contact page with a submission form.
- `css/style.css`: External stylesheet containing all visual designs, colors, and layouts.
- `img/`: Folder containing image assets (hero image).
- `audio/`: Folder containing audio assets (welcome greeting).
- `projects/`: Folder containing specific project detail pages.
    - `project1.html`: 筑语书 with iFrame, list, and button.
    - `project2.html`: Nothing here but a placeholder.
    - `project3.html`: Nothing here but a placeholder.

## Requirements Met
- Semantic HTML tags (`header`, `footer`, `main`, `h1-h3`, `nav`).
- Consistent header and footer across all pages.
- Multi-page navigation (Home, Projects, Contact).
- Multimedia: Image and Audio included on the homepage.
- Project details: iFrame (YouTube embed), bulleted list, and interactive button in `project1.html`.
- Form: Name, Email, and Question fields included in `contact.html`.
- CSS: Uses IDs and classes for specific styling; includes colors, custom fonts, and borders.
